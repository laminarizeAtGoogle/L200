# OKF (Deployed GCP Asset): Argolis Compute Engine Instances

## 1. Executive Summary & Purpose
- **Primary Function**: Managed Google Compute Engine virtual machine instances provisioned in the Argolis sandbox project, hosting AI agent workloads, isolated testing environments, and model evaluation harnesses.
- **Target Audience / Consumer**: Academy L200 engineers, Cloudtop developers running remote agent tests, and automated evaluation pipelines.
- **Key Outcome**: Delivers scalable, isolated compute environments attached to the regional VPC network with secure Cloud IAP (Identity-Aware Proxy) ingress and zero public IP exposure.

## 2. Deployed GCP Asset Context
- **GCP Resource Type**: `compute.instances`
- **Resource Identifier**: `projects/<PROJECT_ID>/zones/us-central1-a/instances/<INSTANCE_NAME>`
- **Discovery Method (Read Agent)**:
  - Discovery SA: `cloudtop-agent-reader@<PROJECT_ID>.iam.gserviceaccount.com` (Viewer / read-only)
  - Inspection Commands:
    ```bash
    # Read-only discovery via SA impersonation
    gcloud compute instances list \
      --project <PROJECT_ID> \
      --impersonate-service-account=cloudtop-agent-reader@<PROJECT_ID>.iam.gserviceaccount.com

    # Standalone helper CLI tool
    ./bin/argolis list
    ```
- **Live State Attributes**:
  - Region / Zone: `us-central1` / `us-central1-a`
  - Network Tier / IP: Internal VPC private IP only (`10.128.0.0/20`), External IP: `None` (Zero public exposure)
  - Lifecycle Status: `RUNNING` / `PROVISIONING` / `TERMINATED`
- **IAM Boundary**: Managed strictly inside the Argolis GCP project perimeter; mutations are restricted to `github-terraform-deployer` via GitHub Actions CD pipeline.

## 3. Technical Specifications & Configuration
- **Terraform Declarations**: Configured declaratively via [`terraform/main.tf`](../../../terraform/main.tf) using `google_compute_instance` resource blocks.
- **Attributes & Configuration**:
  | Attribute | Standard Value | Description |
  |---|---|---|
  | `machine_type` | `e2-medium` | Default VM instance profile (2 vCPU, 4GB RAM) |
  | `zone` | `us-central1-a` | Regional deployment zone |
  | `boot_disk.initialize_params.image` | `debian-cloud/debian-12` | Hardened Debian baseline image |
  | `network_interface` | Custom subnet | VPC internal subnet binding |
  | `network_interface.access_config` | Omitted | Guarantees NO public external IP address |
  | `service_account.scopes` | `["cloud-platform"]` | Scoped execution IAM bindings |
- **Security & IAM Roles**:
  - Provisioning Authority: `github-terraform-deployer` with `roles/compute.admin`
  - Read-Only Inspection: `cloudtop-agent-reader` with `roles/viewer`
  - Ingress Control: Ingress allowed strictly via Identity-Aware Proxy (IAP) on port 22 (`tcp:22`)

## 4. Operational Runbook & Lifecycle
- **Step 1: Provisioning & Update Flow**:
  1. Author modifications to instance parameters in `terraform/main.tf` or `terraform/variables.tf`.
  2. Open pull request; inspect `terraform plan` output generated by `terraform-plan.yml`.
  3. Merge to `main`; `terraform-apply.yml` provisions or updates VMs in the live project.
- **Step 2: Inspection & Health Check**:
  ```bash
  # Check instance health and operational status
  gcloud compute instances describe <INSTANCE_NAME> \
    --zone=us-central1-a \
    --project=<PROJECT_ID> \
    --impersonate-service-account=cloudtop-agent-reader@<PROJECT_ID>.iam.gserviceaccount.com

  # Inspect serial console output for boot diagnostics
  gcloud compute instances get-serial-port-output <INSTANCE_NAME> \
    --zone=us-central1-a \
    --project=<PROJECT_ID> \
    --impersonate-service-account=cloudtop-agent-reader@<PROJECT_ID>.iam.gserviceaccount.com
  ```
- **Step 3: Failure Modes & Blast Radius**:
  - *Symptom*: Instance unreachable or stopped.
    - *Blast Radius*: Confined to workload testing running on that specific VM; zero impact on corporate Cloudtop or CI/CD pipelines.
- **Step 4: Remediation & Incident Recovery**:
  ```bash
  # Restart or stop/start via helper CLI
  ./bin/argolis stop <INSTANCE_NAME>
  ./bin/argolis start <INSTANCE_NAME>
  ./bin/argolis ssh <INSTANCE_NAME>

  # Restart healthy instance state via gcloud
  gcloud compute instances reset <INSTANCE_NAME> \
    --zone=us-central1-a \
    --project=<PROJECT_ID>
  ```
